# MARU 디자인 평가와 개선 기록

## 결과

독립 평가를 두 차례 수행하고, 두 번째 평가의 지적을 수정한 뒤 재확인했다. 최종 잠정 점수는 **29/40점, 72.5점으로 양호**다. 이번 검토에서 설정한 우수 기준 90점에는 도달하지 못했다.

이 점수는 [Nielsen의 10개 사용성 휴리스틱](https://www.nngroup.com/articles/ten-usability-heuristics/)을 바탕으로 정한 내부 품질 척도다. 각 항목은 0점 실패, 1점 중대 문제, 2점 보완 필요, 3점 양호, 4점 근거상 우수로 평가했다. NN/G의 인증이나 공식 점수가 아니다.

현재 실제 화면의 구매 및 모션 통합 검증은 남아 있다. 따라서 이 문서는 배포 승인이나 기능 최종 완료 보고가 아니다.

## 검토 방법

- 1차 A: `nielsen_round1`, 코드 기반 사용성 평가. 새 화면의 미관은 N/A로 제외.
- 1차 B: `evidence_round1`, TSX 자동 탐지와 CSS 선언 및 색상 대비 계산.
- 2차 A: `nielsen_round2`, 1차 점수와 B 결과를 보지 않은 독립 평가. 코드 및 현재 컴포넌트의 정적 SSR 화면 확인.
- 2차 B: `evidence_round2`, 독립 브라우저와 자동 검사. 네 가지 너비의 DOM 측정 및 네이티브 앵커 확인.
- 수정 재확인: 2차 A가 수정 항목만 다시 확인하고 영향받은 점수를 갱신.

각 차수의 A 평가가 끝난 뒤 B 결과를 종합했다. 평가자에게 목표 점수에 맞추어 채점하도록 요청하지 않았다. 새로운 검토 질문은 생략했다. 사용자가 구현과 최소 두 차례 검토를 이미 요청했으며, 확인된 수정은 해당 범위에 포함된다.

1차는 미관을 제외한 9항목, 2차부터는 정적 미관을 포함한 10항목이다. 단순한 백분율 상승만으로 같은 조건의 성능 향상처럼 해석하지 않는다. 공통 9항목만 비교하면 **24/36에서 26/36**으로 개선됐다. 2차에 사진 불일치가 새로 확인되면서 인식 항목은 낮아졌다.

## 적용한 개선

1. 전시 배너와 별도 상품 가격을 함께 표시하지 않도록 했다. 상품 fallback에서만 해당 상품의 정확한 가격을 표시하고 단일 가격의 ‘부터’ 표현을 제거했다.
2. 히어로에 ‘이번 계절의 상품 바로 보기’를 추가했다. 추천 전시가 숨겨지거나 비어 있으면 링크도 표시하지 않는다.
3. 홈 하단 서비스 영역을 실제 주문 상태, 비회원 주문 조회, FAQ 경로로 연결했다. 이용할 수 있는 지원 내용과 행동이 일치하도록 했다.
4. 홈 데이터를 불러오지 못해도 재시도와 독립적으로 열 수 있는 쇼핑 도움말을 함께 제공한다.
5. 모션 감소 설정에서도 아래쪽 탐색 화살표와 대각 링크의 기본 방향을 유지한다.
6. 목적지가 단일 상품이고 CTA가 일반적인 ‘컬렉션 보기’일 때만 ‘상품 자세히 보기’로 조정한다. 관리자가 지정한 다른 배너 문구는 보존한다.
7. 경로 없는 컨시어지 안내를 제거하고 푸터 도움말에 실제 FAQ 링크를 연결했다.
8. NEW, LIMITED, PICK 배지를 한국어로 통일했다. 홈의 버튼과 상품 제목 링크에 최소 44px 크기를 적용했다.

## 확인한 증거

### 정적 화면과 DOM

프리뷰는 실제 `HomePage`, `StoreLayout`, 상품 카드 및 시네마틱 컴포넌트를 React SSR로 렌더했다. 읽기 전용 홈 API 스냅샷을 사용했으며 최종 재확인에는 기존 `normalizeHomeData`와 `normalizeCategory`도 적용했다. 새 API 실행 주소를 지정하지 않았다.

프리뷰에는 클라이언트 hydration이 없다. 이는 기본 정적 배치와 네이티브 링크를 확인하는 근거이며, 실제 Next.js 앱의 모션과 구매 동작을 검증한 결과가 아니다.

| 검사 | 결과 |
| --- | --- |
| 화면 너비 390, 768, 1280, 1440px | 문서 가로 넘침 없음 |
| 주요 홈 링크 11개 | 네 너비에서 44px 이상 |
| 최종 상품 제목 링크 8개 | 데스크톱 높이 47.5px, 모바일 44px |
| 화면에 표시한 이미지 | 13/13 로드 완료 |
| 추천 상품 앵커 | 실제 클릭 후 제목이 화면 안에 도착하고 고정 헤더에 가리지 않음 |
| 정적 프리뷰 리소스 | B가 관찰한 요청 실패와 HTTP 400 이상 응답 0건 |
| TSX 자동 탐지 | 1차와 2차 모두 0건. CSS 및 접근성 전체 통과 의미는 아님 |

1차 B가 계산한 불투명 토큰의 본문 대비는 ink/background 16.76:1, ink-soft/background 8.46:1, primary/background 8.85:1이다. 실제 사진 위 합성 픽셀 측정값이 아니다.

### 코드 검증

- `npm run qa`: 앞선 구현 단계에서 린트, 타입 검사, 프로덕션 빌드, API 테스트 41개 통과.
- 이번 개선 후 프런트엔드 린트와 TypeScript를 포함한 프로덕션 빌드 통과.
- 실제 HomePage를 제어된 서버 데이터로 실행한 fixture 검증 7건 통과: 배너 가격 분리, 상품 가격 일치, HERO 숨김, 상품 CTA 문구, 카테고리 숨김, 추천 숨김, 실패 시 복구 경로.
- E2E에 상품 바로가기와 가격 표현 회귀 조건을 추가했고 테스트 파일 구문 검사는 통과했다. 통합 E2E 실행은 대기 중이다.

## 인지부하와 대표 사용자

1차는 판정 가능한 여섯 항목에서 실패 0개, 시각 관련 두 항목은 보류했다. 2차 정적 화면은 여덟 항목에서 실패 0개로 평가했다. 이 결과가 실제 구매 단계의 인지부하까지 검증한 것은 아니다.

- 첫 방문자는 이제 상품 CTA의 목적지를 문구에서 예상할 수 있고, 도움말을 찾을 수 있다.
- 빠르게 비교하는 방문자는 긴 공간 소개를 건너뛰어 추천 상품으로 이동할 수 있다.
- 모바일 방문자는 주요 링크와 상품 제목의 클릭 영역을 확보했다.
- 사진으로 상품을 비교하는 방문자에게는 아래의 미해결 문제가 남는다.
- 스크린리더 발표, 키보드 구매, 장바구니 상태 전환과 모션 민감 사용자의 실제 경험은 통합 검증이 필요하다.

## 남은 문제와 우수 평가 조건

### P2: 상품명과 사진의 불일치

정적 프리뷰에서 린넨 베드 세트에 거실 사진, 커브 플로어 램프에 컵 사진이 나타난다. 현재 ProductCard가 받은 API 이미지 자체의 문제로 확인했다. 임의의 다른 상품 사진이나 생성 이미지를 실제 제품 사진으로 간주해 교체하지 않았다. 각 상품과 일치하는 검증된 이미지 연결이 필요하다.

### 미검증: 실제 모션과 구매 통합

로컬 API 주소 조정 명령이 자동 승인 검토에서 `blocked by policy`로 거절됐다. 기존 실행 환경의 주소에 붙은 `/api`와 클라이언트가 추가하는 `/api/v1`이 중복되는 상태다. 실행에 한정한 주소 조정 허용 요청은 답변 대기다. 저장된 환경 파일은 수정하지 않았다.

따라서 실제 hydration 이후 스크롤 전환, 포인터 반응, 모션 감소 전환, 장바구니와 찜, 오류 재시도, Chromium 및 WebKit E2E, 프레임률과 웹 성능은 확인하지 못했다. 정적 프리뷰에서 이를 통과했다고 주장하지 않는다.

높은 점수는 이 근거를 추가하고 약한 항목을 개선한 뒤 다시 판단해야 한다. 우수 기준을 낮추거나 미검증 항목을 임의로 4점 처리하지 않는다.

## 근거 파일

후속 데스크톱 구성 개선이 이 평가 이후 적용됐다. 첫 화면 좌우 배치와 카테고리 세 열을 도입했고, 반응형 열 수를 모션 활성 여부와 분리했다. 해당 변경은 별도의 레이아웃 검증을 받았으며 위 Nielsen 점수를 새 화면의 재평가 점수로 사용하지 않는다. 현재 구현과 확인 범위는 `DESIGN.md`, `.omx/desktop-layout-results.json`을 따른다.

이후 첫 원격 CI에서 로컬 배너 문구를 가정한 테스트와 JavaScript 없는 전체 앱 탐색 전제가 맞지 않음을 확인했다. 배너 검사는 실제 홈 요소와 접근 가능한 이름을 확인하도록 바꿨다. JavaScript 비활성 상태는 무기한 로딩 대신 브라우저 설정 안내를 제공하는 것으로 명시했으며, 정적 SSR 배치와 전체 앱 지원 범위를 구분한다. WebKit에서 강제 문서 이동이 진행 중인 prefetch를 취소한 trace를 확인해, 테스트 복귀 동작을 실제 홈 링크 클릭으로 수정했다. 오류 검사나 보안 헤더를 완화하지 않았다.

- `.omx/nielsen-round1-b.md`, `.omx/nielsen-round1-b.json`
- `.omx/nielsen-round2-b.md`, `.omx/nielsen-round2-b-dom.json`
- `.omx/nielsen-round2-desktop.png`, `.omx/nielsen-round2-mobile.png`
- `.omx/nielsen-round2-desktop-section.png`, `.omx/nielsen-round2-mobile-section.png`
- `.omx/home-contract-results.json`
- `.omx/render-home-preview.cjs`, `.omx/check-home-contracts.cjs`, `.omx/serve-home-preview.cjs`

`.omx`는 로컬 검토 자료이며 Git에 포함되지 않는다. 검토용 정적 서버는 평가가 끝난 뒤 종료한다. 독립 평가 및 점수의 영구 기록은 이 문서와 `.impeccable/critique` 스냅샷에 남긴다.
